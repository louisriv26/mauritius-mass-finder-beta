Aide de la collection

L’essentiel

Collection Luisa est une porte d’entrée vers quatre applications indépendantes consacrées aux écrits de Luisa Piccarreta.

Chaque application gère séparément ses textes, ses réglages ainsi que vos notes, surlignages, favoris et progression.

Vous pouvez utiliser Collection Luisa dans votre navigateur ou l’ajouter à votre écran d’accueil. L’installation est facultative.

Installer Collection Luisa

Ajoutez une icône Collection Luisa à votre écran d’accueil pour accéder facilement aux quatre applications. L’installation est facultative et ne nécessite pas de compte.

Choisissez les instructions correspondant à votre appareil :

Sur iPhone
  1. Ouvrez Collection Luisa dans Safari.
  2. Touchez le menu de la page, puis Partager (ou directement le bouton Partager, selon la présentation de Safari).
  3. Choisissez Sur l’écran d’accueil. Si cette option n’apparaît pas, faites défiler les actions jusqu’en bas, touchez Modifier les actions et ajoutez Sur l’écran d’accueil.
  4. Activez Ouvrir comme app web si cette option est proposée, puis touchez Ajouter.
Sur iPad
  1. Ouvrez Collection Luisa dans Safari.
  2. Touchez le bouton Partager et choisissez Sur l’écran d’accueil (au besoin, touchez En voir plus).
  3. Activez Ouvrir comme app web si cette option est proposée, puis touchez Ajouter.
Sur Android
  1. Ouvrez Collection Luisa dans Chrome.
  2. Ouvrez le menu du navigateur ⋮, puis choisissez Installer l’application, Installer ou Ajouter à l’écran d’accueil, selon les options proposées.
  3. Confirmez. Vous retrouverez ensuite Collection Luisa sur votre écran d’accueil.
Sur ordinateur
  1. Dans Chrome, ouvrez Collection Luisa, puis ⋮ > Caster, enregistrer et partager > Installer la page en tant qu’appli. Selon votre version, l’option d’installation peut aussi apparaître dans la barre d’adresse.
  2. Sur Mac avec Safari, utilisez Partager puis Ajouter au Dock.
  3. Confirmez l’ajout si le navigateur vous le demande.

Vous ne trouvez pas l’option d’installation ?

Si vous avez ouvert le lien depuis WhatsApp, un courriel ou une autre application, ouvrez cette même adresse directement dans Safari sur iPhone/iPad ou dans Chrome sur Android, puis suivez les étapes ci-dessus. Les intitulés des menus peuvent varier selon le navigateur et sa version.

Important : l’icône installe uniquement la porte d’entrée Collection Luisa, pas les quatre applications séparément. Chaque application conserve son fonctionnement et ses données de lecture. Selon la manière dont vous l’ouvrez, son espace de stockage peut être différent. Si des notes ou surlignages semblent absents, revenez d’abord à votre méthode d’accès habituelle, sans effacer les données du navigateur.

À quoi sert Collection Luisa ?

Collection Luisa rassemble en un seul endroit l’accès aux quatre applications. Elle permet de choisir une œuvre et d’ouvrir l’application correspondante, sans fusionner les applications ni leurs données.

Dois-je installer les quatre applications ?

Non. Vous pouvez ouvrir les quatre applications depuis Collection Luisa sans les ajouter séparément à votre écran d’accueil. Si vous utilisez régulièrement une application, vous pouvez aussi l’ajouter directement à votre écran d’accueil.

Que se passe-t-il lorsque j’ouvre une application ?

Collection Luisa ouvre l’adresse de l’application choisie. L’endroit où elle s’affiche — dans le navigateur ou, selon l’appareil, dans une application web déjà installée — dépend de votre appareil et de votre navigateur. Collection Luisa ne force pas ce choix.

Comment revenir à Collection Luisa ?

Après avoir ouvert une application, vous pouvez revenir avec la commande Retour de votre navigateur lorsqu’elle est disponible, ou rouvrir Collection Luisa depuis son adresse ou son icône si vous l’avez ajoutée à votre écran d’accueil.

Où sont conservés mes notes, surlignages, favoris et progression ?

Chaque application gère ses propres données de lecture. Selon l’appareil, le navigateur et la manière dont vous ouvrez une application, une version utilisée dans le navigateur et une version ajoutée séparément à l’écran d’accueil peuvent parfois utiliser des espaces de stockage distincts.

Pourquoi mes données peuvent-elles sembler absentes ?

Si vos notes, surlignages, favoris ou votre progression semblent absents, vérifiez d’abord que vous ouvrez l’application de la même manière qu’auparavant. Effacer les données du navigateur ou du site peut supprimer les données enregistrées localement. Lorsqu’une fonction de sauvegarde ou d’export est proposée dans une application, utilisez-la pour les données importantes.

Mes données sont-elles partagées entre les applications ?

Non. Collection Luisa ne lit, ne rassemble ni ne synchronise vos notes, surlignages, favoris ou progression. Chaque application reste indépendante.

Les réglages de Collection Luisa modifient-ils les quatre applications ?

Non. Le thème et la taille du texte choisis dans Collection Luisa s’appliquent uniquement à Collection Luisa. Chaque application conserve ses propres réglages.

Que signifie « Actualiser » ?

Lorsqu’une nouvelle version de Collection Luisa est disponible, le message « Mise à jour disponible » apparaît avec le bouton « Actualiser ». « Actualiser » met à jour Collection Luisa uniquement. Les quatre applications sont indépendantes ; leurs mises à jour ne sont pas gérées par Collection Luisa. Collection Luisa ne modifie pas leurs notes, surlignages, favoris ou progression.

Puis-je utiliser Collection Luisa hors connexion ?

Après avoir été chargée sur l’appareil, Collection Luisa peut continuer à s’ouvrir hors connexion. En revanche, Collection Luisa ne rend pas elle-même les quatre applications disponibles hors connexion. Leur fonctionnement hors connexion dépend de ce que chacune a déjà rendu disponible sur votre appareil.

Comment ajouter Collection Luisa à mon écran d’accueil ?

Consultez le guide d’installation par appareil ci-dessus. Vous pouvez également continuer à utiliser Collection Luisa dans le navigateur. Chaque application conserve ses données et ses réglages séparément.
