Aide de la collection

L’essentiel

Collection Luisa est une porte d’entrée vers quatre applications indépendantes consacrées aux écrits de Luisa Piccarreta.

Chaque application gère séparément ses textes, ses réglages ainsi que vos notes, surlignages, favoris et progression.

Vous pouvez utiliser Collection Luisa dans votre navigateur ou l’ajouter à votre écran d’accueil. L’installation est facultative.

Installer Collection Luisa

Ajoutez Collection Luisa à votre téléphone, tablette ou ordinateur pour accéder plus facilement aux quatre applications.

L’installation est gratuite, facultative et sans compte. Aucun passage par l’App Store ou Google Play n’est nécessaire. Vous pouvez aussi continuer à utiliser la collection dans votre navigateur.

Comment procéder ? Ouvrez les instructions de votre appareil ci-dessous, lisez les étapes, puis utilisez le lien « Revenir à l’accueil pour installer » pour effectuer l’installation depuis la page d’accueil.

Revenir à l’accueil pour installer

Sur iPhone
  1. Ouvrez la page d’accueil de Collection Luisa dans Safari.
  2. Touchez Partager (l’icône avec un carré et une flèche vers le haut). Selon la présentation de Safari, ouvrez d’abord le menu de la page.
  3. Choisissez Sur l’écran d’accueil dans les options de partage.
  4. Si l’option Ouvrir comme app web apparaît, laissez-la activée.
  5. Touchez Ajouter.

Vérification : touchez la nouvelle icône Collection Luisa sur votre écran d’accueil. Vous devez retrouver les quatre applications.

Option absente ? Faites défiler les actions de partage ; si Modifier les actions est proposé, utilisez-le pour afficher Sur l’écran d’accueil.

Sur iPad
  1. Ouvrez la page d’accueil de Collection Luisa dans Safari.
  2. Touchez Partager, généralement en haut de l’écran.
  3. Choisissez Sur l’écran d’accueil ; touchez En voir plus si nécessaire.
  4. Laissez Ouvrir comme app web activé si cette option apparaît, puis touchez Ajouter.

Vérification : ouvrez la nouvelle icône sur votre écran d’accueil. La page des quatre applications doit s’afficher.

Sur Android
  1. Ouvrez la page d’accueil de Collection Luisa dans Chrome.
  2. Touchez le menu ⋮ de Chrome.
  3. Choisissez Installer et créer un raccourci, puis Installer, si ces options sont proposées.
  4. Confirmez l’installation et ouvrez Collection Luisa depuis son icône.

Option différente ? Les menus peuvent indiquer Installer l’application ou Ajouter à l’écran d’accueil. Si seul Créer un raccourci est proposé, vous pouvez créer un accès à la collection, mais il peut s’ouvrir dans le navigateur plutôt que comme une application indépendante.

Sur ordinateur

Google Chrome

  1. Ouvrez la page d’accueil de Collection Luisa dans Chrome.
  2. Cliquez sur ⋮ puis, selon votre version, Caster, enregistrer et partager → Installer la page en tant qu’appli, ou sur le bouton d’installation dans la barre d’adresse.
  3. Confirmez l’installation.

Microsoft Edge

  1. Ouvrez la page d’accueil de Collection Luisa dans Edge.
  2. Cliquez sur ⋯ → Applications → Installer ce site en tant qu’application. Selon la version, Applications peut être dans Autres outils.
  3. Confirmez l’installation.

Safari sur Mac

  1. Ouvrez la page d’accueil de Collection Luisa dans Safari.
  2. Choisissez Fichier → Ajouter au Dock (ou Partager → Ajouter au Dock).
  3. Cliquez sur Ajouter. Cette fonction nécessite macOS Sonoma 14 ou plus récent.

Vérification : ouvrez Collection Luisa depuis son icône et vérifiez que les quatre applications apparaissent.

Revenir à l’accueil pour installer

Vous avez ouvert le lien depuis WhatsApp ou un courriel ?

Si les commandes d’installation n’apparaissent pas, choisissez Ouvrir dans le navigateur si cette option est proposée. Sinon, copiez l’adresse de la page d’accueil et ouvrez-la dans Safari sur iPhone/iPad ou Chrome sur Android, puis suivez les étapes ci-dessus.

Si votre appareil est en anglais, les menus peuvent notamment s’appeler Share, Add to Home Screen, Open as Web App ou Install.

Collection Luisa est déjà installée ?

Si vous avez déjà une icône qui ouvre la page des quatre applications, vous n’avez rien d’autre à faire.

Bon à savoir

Quatre applications indépendantes. Installer Collection Luisa ajoute une porte d’entrée pratique ; cela n’installe pas séparément les quatre applications et ne rassemble pas leurs données.

Vos annotations. L’installation du hub ne supprime pas vos notes, favoris ou surlignages. Selon la manière dont vous ouvrez chaque application, vos données peuvent toutefois apparaître dans des espaces de stockage différents. Si elles semblent absentes, utilisez votre méthode d’accès habituelle. N’effacez pas les données du navigateur.

Hors connexion. Collection Luisa peut rester accessible après un premier chargement, mais son installation ne rend pas automatiquement les quatre applications disponibles hors connexion.

À quoi sert Collection Luisa ?

Collection Luisa rassemble en un seul endroit l’accès aux quatre applications. Elle permet de choisir une œuvre et d’ouvrir l’application correspondante, sans fusionner les applications ni leurs données.

Dois-je installer les quatre applications ?

Non. Vous pouvez ouvrir les quatre applications depuis Collection Luisa sans les ajouter séparément à votre écran d’accueil. Si vous utilisez régulièrement une application, vous pouvez aussi l’ajouter directement à votre écran d’accueil.

Que se passe-t-il lorsque j’ouvre une application ?

Collection Luisa ouvre l’adresse de l’application choisie. L’endroit où elle s’affiche — dans le navigateur ou, selon l’appareil, dans une application web déjà installée — dépend de votre appareil et de votre navigateur. Collection Luisa ne force pas ce choix.

Comment revenir à Collection Luisa ?

Après avoir ouvert une application, vous pouvez revenir avec la commande Retour de votre navigateur lorsqu’elle est disponible, ou rouvrir Collection Luisa depuis son adresse ou son icône si vous l’avez ajoutée à votre écran d’accueil.

Où sont conservés mes notes, surlignages, favoris et progression ?

Chaque application gère ses propres données de lecture. Selon l’appareil, le navigateur et la manière dont vous ouvrez une application, une version utilisée dans le navigateur et une version ajoutée séparément à l’écran d’accueil peuvent parfois utiliser des espaces de stockage distincts.

Pourquoi mes données peuvent-elles sembler absentes ?

Si vos notes, surlignages, favoris ou votre progression semblent absents, vérifiez d’abord que vous ouvrez l’application de la même manière qu’auparavant. Effacer les données du navigateur ou du site peut supprimer les données enregistrées localement. Lorsqu’une fonction de sauvegarde ou d’export est proposée dans une application, utilisez-la pour les données importantes.

Mes données sont-elles partagées entre les applications ?

Non. Collection Luisa ne lit, ne rassemble ni ne synchronise vos notes, surlignages, favoris ou progression. Chaque application reste indépendante.

Les réglages de Collection Luisa modifient-ils les quatre applications ?

Non. Le thème et la taille du texte choisis dans Collection Luisa s’appliquent uniquement à Collection Luisa. Chaque application conserve ses propres réglages.

Que signifie « Actualiser » ?

Lorsqu’une nouvelle version de Collection Luisa est disponible, le message « Mise à jour disponible » apparaît avec le bouton « Actualiser ». « Actualiser » met à jour Collection Luisa uniquement. Les quatre applications sont indépendantes ; leurs mises à jour ne sont pas gérées par Collection Luisa. Collection Luisa ne modifie pas leurs notes, surlignages, favoris ou progression.

Puis-je utiliser Collection Luisa hors connexion ?

Après avoir été chargée sur l’appareil, Collection Luisa peut continuer à s’ouvrir hors connexion. En revanche, Collection Luisa ne rend pas elle-même les quatre applications disponibles hors connexion. Leur fonctionnement hors connexion dépend de ce que chacune a déjà rendu disponible sur votre appareil.
